> **HermexPay Hosted Checkout** — ізольований мікрофронтенд захищеного платіжного шлюзу (аналог Stripe Checkout та Apple Pay).  
> Забезпечує безпечне введення платіжних даних поза клієнтською вітриною, містить інтерактивну 3D-картку з металевим EMV-чіпом, незбивний 15-хвилинний таймер резерву та тестову лабораторію Saga.

## ✨ Ключові можливості

### 1. Преміальна світла фінтех-естетика (Стандарт Stripe)
- Чистий повітряний фон (`bg-slate-50` / `bg-white`), гармонійні межі та високий контраст.
- Усунено зайві dev-бейджі. Додано лаконічне повідомлення довіри:  
  *«Безпечна оплата. Hermex не зберігає дані банківських карток.»*

### 2. Захищений сесійний доступ (No Public Root)
- Кореневий URL `/` безпечно перенаправляє на вітрину `website`.
- Оплата доступна виключно за сесійним посиланням `/pay/[id]` з валідацією через API Gateway.

### 3. Інтерактивна 3D-картка (`PaymentCardVisualizer`)
- Реалістичний металевий EMV-мікрочіп із золотистими доріжками.
- Компактне форматування номеру 4-значними блоками: `4242 4242 4242 4242`.
- Плавна 3D-анімація перевороту картки зворотним боком при введенні CVV.

### 4. Незбивний 15-хвилинний таймер резерву
- Розрахунок від серверного часу створення замовлення (`createdAt` + 15 хв).
- Синхронізація з годинником (`Date.now()`) та збереження в `localStorage`.
- При натисканні **F5**, оновленні вкладки чи відкритті в новому вікні таймер **не скидається** на 15:00.
- Позиції та сума замовлення зберігаються без блимання.

### 5. Згортана лабораторія Saga (Developer Mode)
- Акуратний акордеон: `[ 🧪 Тестова лабораторія Saga (Developer Mode) ]`.
- Тестування всіх сценаріїв розподіленої Saga в 1 клік:
  - `[ ✅ Успіх ]` ➔ `4242...4242` (`payment.succeeded` ➔ замовлення підтверджено).
  - `[ ❌ Недостатньо коштів ]` ➔ `4000...0002` (`payment.failed` ➔ повернення на склад ➔ скасовано).
  - `[ 🚫 Картка прострочена ]` ➔ `4000...0003`.
  - `[ 🛑 Відхилено банком ]` ➔ `4000...0004`.
  - `[ ⏱️ Таймаут ]` ➔ `4000...0005`.

### 6. Модальне вікно процесингу та 3D-Secure
- Покрокова анімація перевірки сесії, зв'язку з банком та списання.
- Автоматичний редирект назад до трекера замовлення на вітрині.
